# Changelog

## 0.2.3 — 2026-10-05
- Package metadata: homepage https://baaslatam.com/developers, repository and issue tracker on GitHub.

## 0.2.2 — 2026-10-05
- First public release on npm.
- Fast on-device card detector (corners + front/back) by default, preloaded off the main thread.
- Photo review after each document side ("Repetir" / "Usar esta foto").
- Face scan mesh fitted to facial landmarks.
- Phone handoff (QR / link) from desktop, device diagnostics, readable failure reasons in `onFailed` detail.
- Models served from the BaaS CDN by default.
